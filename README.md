# Vrinda Store Data Analysis – Excel

## Project Overview
Analyzed Vrinda Store's 2022 sales data using Microsoft Excel to understand sales trends, customer behavior, and order performance.

## Objectives
- Analyze monthly sales and order trends.
- Understand customer purchasing patterns by gender and age group.
- Identify top-performing states and sales channels.
- Analyze order status and fulfillment performance.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel Dashboard and Data Visualization

## Key Analysis
- Monthly Orders vs Sales
- Men vs Women Sales Analysis
- Age Group and Gender Analysis
- Order Status Analysis
- Top 5 States by Sales
- Sales Channel Analysis

## Files Included
- Vrinda Store Data Analysis.xlsx – Excel workbook containing the analysis and dashboard.

## Conclusion
This project demonstrates how Excel can be used to analyze retail sales data, visualize trends,
and generate insights to support data-driven business decisions.
